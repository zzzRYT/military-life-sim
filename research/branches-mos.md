# 병과(兵科)·주특기(MOS) 체계 리서치

- 조사일: 2026-10-14
- 목적: military-life-sim 추첨 시스템(`draw.js` §6: 신체등급→신분→군종→경로→특기)의 병과→주특기 판별을 실제 데이터 기반으로 전환. 현재 `mos`는 전부 "가정" 상태.
- 표기 규칙: `research/official.md`와 동일. `[Sx]` = 기존 코드(S1~S52) 재사용, `[S_new_n]` = 이번 조사에서 새로 제안하는 코드(맨 아래 출처 목록 참조). 공식 출처가 없는 값은 **가정**으로 명기.
- 신뢰도: **공식** = 법령/병무청/국방부/정부 원문. **차선** = 정부기관 보도·언론·위키(원전 인용) 등. **없음** = 미확인.

## 1. 병과 체계 개요 (전군 공통)

군인사법 제5조와 군인사법 시행령 제2조의2에 따라 병과는 **기본병과**(전투/기술/행정)와 **특수병과**로 구분된다 [S3][S_new_1].

| 구분 | 내용 |
|---|---|
| 전투병과 | 직접 전투에 참전하는 병과 |
| 기술병과 | 기술적 지원 (정보통신·공병·항공·화생방·병기·병참·수송 등) |
| 행정병과 | 인사·군악·군사경찰·재정·공보정훈 등 군 유지 지원 |
| 특수병과 | 의무·법무·군종 (장교 중심, 병은 의무·법무행정·군종행정 특기로 존재) |

참고: 2014-10-01 육군은 병기·병참·수송을 묶어 **군수** 병과를 창설(장교 중심), 2012-01-21 해군은 항해·기관·정보 특기를 **함정** 병과로 통합, 2020-02 헌병→**군사경찰** 개칭, 경리→**재정** 개칭 [S_new_1].

## 6. 병 주특기 부여 방식 (특기분류) — 게임 판별 로직 근거

| 군종 | 경로 | 부여 방식 | 게임 적용 |
|---|---|---|---|
| 육군 | 징집병(conscript) | 신병교육 수료 후 **특기분류**. 희망·적성 반영 후 전산 분류되며, 부대 인력운영 수준 초과 등 분류가 제한될 경우 **무작위 전산분류** [S_new_8] | `mos = wpick(mos[branch])` — 현 draw.js 구조 유지. 가중치는 공식 분포 없음 → **가정** |
| 육군 | 모집병(volunteer) | 지원한 특기대로 선발 (기술행정병·전문특기병 등) [S31][S_new_7] | `mos` = 지원 특기 (플레이어 선택 or 지원 특기 테이블에서 추첨) |

| 해병대 | 일반병 | 2027년부터 무작위 전산 선발 [S_new_7]. 교육단에서 특기분류 (세부 미확인) | **가정**: 육군과 유사 |

## 7. 부사관·장교 병과 분류 (간략, M3 범위)

- **육군 장교**: 병과 + 병과세부특기 (육군규정 110). 보병(일반/특전/특임)·기갑(전차승무·정비·장갑차)·포병(야전·로켓·표적·현무)·방공·정보(인간/신호/영상/UAV)·공병·정보통신·항공·군사경찰·수사 [S_new_4]. 임관 시 성적·희망으로 병과 선택.
- **육군 준사관**: 준사관 특기 (육군규정 111) [S_new_4].
- **육군 부사관**: 병과 + 부사관 세부특기 (육군규정 112). 장교 병과와 동일 체계, 세부특기 일부 상이 [S_new_4].
- **해군 장교**: 함정(항해/기관)·항공·정보·정보통신·병기·보급·공병·조함 등 (해군 분과규정) [S_new_4].
- 게임 적용(M3): 간부는 입직 시 병과 선택 이벤트(성적·희망 기반). 본 문서는 체계 정리까지만.

## 8. 게임 적용 제안 (weights.json)

```json
"mos": {
  "army": {
    "infantry":  { "w": 0, "src": "가정", "codes": ["111101","111102","111108","111110"] },
    "armor":     { "w": 0, "src": "가정", "codes": ["121101","122101","123101"] },
    "artillery": { "w": 0, "src": "가정", "codes": ["131101","131103","131107","132101"] }
  },
  "navy":   { "deck": {...}, "weapon": {...}, "engine": {...} },
  "airforce": { "airdefense": {...}, "supply": {...}, "comms": {...} },
  "marine": { "infantry": {...}, "artillery": {...} }
}
```

- `branch`(병과) 추첨 후 `mos`(주특기)는 해당 병과의 대표 특기 목록에서 추첨. 주특기번호 6자리는 플레이어에게 보여주는 "디테일"로 활용 (예: 배치 통지서 카드에 "111101 소총수" 표기).
- 병과별 인원 가중치(`w`)는 **공식 분포 없음 → 전부 가정**. 보병 비중이 압도적이라는 점만 상식으로 반영.
- `route=volunteer`이면 `mos`를 플레이어 선택지로 제시 (지원 특기 = 모집병 특기).
- 자격증·전공(`flags.certs/major`)은 기존 `adjust()` 로직대로 특정 특기 가중치 상승에 사용 (예: 운전면허→수송, 전산 자격→정보통신).

## 9. 가정으로 남긴 항목 (assumptions.json 행)

1. **병과별 인원 가중치** — 병과별 현역병 분포의 공식 통계 없음. 전군 통틀어 보병이 최대 다수라는 것만 상식.
2. **해군 병 특기의 현행 직별부호·명칭** — 1996년 법령 별지(구자료)와 한국산업인력공단 자료(차선) 기반. 2012년 병과 개편 후 병 특기 체계의 현행 전체 목록 미확보.
3. **해병대 병 특기 전체 목록** — 일부(보병·포병·기갑·상륙장갑·군수계열·헌병)만 확인. 행정·의무·군악 등은 육·해군과 동일 체계로 가정.
4. **공군 병 특기** — 2022년 병무청 일람표 기반. 이후 변경분 미반영 가능.
5. **주특기번호 현행 유효성** — 위키백과 자료는 2012년 개편 기준. 이후 연례 개정분 미반영 가능. 게임 내 표기는 "대표 번호" 수준으로 사용 권장.
6. **특기분류 세부 알고리즘** — 공군의 지망+점수 방식은 커뮤니티 출처라 규칙 상세 미확인. 해군·해병대 특기분류 절차 미확인.
7. **해병대 수색 특기** — 보병 병과 내 특기로 분류 (모집 시 수영·스쿠버 자격 가점). 정식 특기명·번호 미확인.
