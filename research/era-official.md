## 0. 핵심 결론 (엔진 설계자가 먼저 볼 것)

1. **복무기간은 "입영일 -> 개월 수 + 감축일수" 규칙으로 완전히 계산된다.** 2006~2011 단계는 21일(3주)마다 1일, 2011-01~02 육군은 14일마다 1일, 2017~2020 단계는 14일(2주)마다 1일씩 감축한다. 시행령 별표 5의 입영일별 조견표 구간 경계 35개와 국방부 예시 8개 입영일(총 43개)에 직접 대입해 **전부 일치**를 확인했다(1-3절). [S_era_1][S_era_2]
2. 2018 단축의 **법령상 기준은 "전역일"**(`'18.10.~'21.12월 전역자: 2주단위 1일씩`)이지만, 같은 별표의 조견표는 **입영일 14일 창**으로 환산돼 있다. 엔진은 입영일 기준 식을 쓰면 된다. [S_era_1][S_era_9]
3. 병 봉급은 e-나라지표(원출처 공무원보수규정 별표 13)에서 **1990~2026 전 연도**를 확보했다. 병장 월 9,400원(1990) -> 1,500,000원(2026). [S_era_3]
4. 휴대전화: 시범 2018-04 -> 전 부대 시범 2019-04 -> **2020-07-01 일과 후 전면 시행**(평일 18~21시) -> 2024-08-07 "일과 후 사용 유지" 결정. 2026-10 현재까지 시간 확대는 없음(검색 범위 내). [S_era_37][S_era_38][S_era_12][S_era_40]
5. 사건사고 통계의 공식 연속 시계열은 **군 사망사고(1993~2025, e-나라)** 와 **군 자살률(2000~2025)** 뿐이다. 탈영은 출처마다 정의가 달라 연속 시계열이 없고, **구타·가혹행위 적발 건수의 전군 연도별 공식 시계열은 2016년 이전 확인 불가**다. [S_era_4][S_era_6]
6. 시대 구간 제안: **~2004 / 2005~2013 / 2014~2017 / 2018~2021 / 2022~** (7절). 구간별 '부조리 강도' 연평균(**가공**): 0.53(1993~96 0.84, 1997~2004 0.38) / 0.39 / 0.13 / 0.11 / 0.28. 엔진 상수 제안(`가정`, 0.05 단위): 0.55 / 0.40 / 0.15 / 0.10 / 0.30.

[S_era_1][S_era_2]
- 전역일 산식 `입영일 + N개월 - 1일 - 감축일수`는 국방부 예시 4건과 일치한다(예: 육군 21개월 입영 2017-01-03 -> 2018-10-02 전역이 원래일, 1일 단축 -> 10-01) [S_era_20][S_era_2]. 월말 입영(예: 31일)의 월 계산 보정은 병무청 계산기 방식을 확인 못 해 **`가정`**(말일로 clamp).
- 계산 예(모두 위 식 결과, **가공**): 육 2008-06-10 입영 -> 24개월에서 -43일 -> 2010-04-27 전역(687일). 육 2012-05-14 -> 21개월 -> 2014-02-13(641일). 육 2018-03-12 -> -31일 -> 2019-11-10(609일). 해 2019-05-20 -> -67일 -> 2021-02-11(634일). 공 2019-05-20 -> -69일 -> 2021-03-11(662일). 육 2023-05-08 -> 18개월 -> 2024-11-07(550일).
- 복무기간에 산입되지 않는 날(형집행·군기교육·복무이탈)은 현행 병역법 시행령 제27조 [S2]·병역법 제18조 [S1]. 영창이 군기교육으로 바뀐 뒤(2020-08-05)에도 교육 일수만큼 전역이 늦어진다 [S_era_44][S_era_11].

공식 통계로 안정적으로 이어지는 결과 지표만 사용하고, 입건·적발 건수는 신고 문화 변화 때문에 제외한다(5-4절).

```
B(연도) = 가중평균( 0.4 * N(사망/만명;  1.0, 6.3),
                    0.2 * N(군 자살/10만; 7.1, 15.2),     # e-나라 2000~. 이전 연도는 제외
                    0.4 * N(탈영/만명;   1.4, 19.1) )     # 2007~2021만. 없는 연도는 제외 후 가중치 재정규화
N(x; lo, hi) = clamp((x - lo) / (hi - lo), 0, 1)            # lo/hi는 위 관측 최소/최대
```

- 앵커: 사망/만 1.0(2020) ~ 6.3(1994), 자살/10만 7.1(2020) ~ 15.2(2011), 탈영/만 1.4(2021) ~ 19.1(2007). **가중치 0.4/0.2/0.4는 `가정`**(출처 없음).
