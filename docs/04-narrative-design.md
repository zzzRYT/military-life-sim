# 04. 서사 설계: 흔적·줄기·연출 감독

> 한 줄: **앞에서 한 일이 뒤에서 돌아온다.** 같은 육군 병사라도 훈련소에서 손을 들었는지, 가스실을 뛰쳐나갔는지에 따라 자대에서 만나는 일이 달라져야 한다.

---

## 1. 지금 무엇이 문제인가

육군 병사 60판을 자동으로 돌려 측정했다 (`boot-camp` 브랜치 기준).

| 지표 | 값 | 뜻 |
|---|---|---|
| 판당 서로 다른 사건 | 27.4개 (전체 97개 중) | — |
| 두 판이 겹치는 사건 비율 (평균 Jaccard) | **0.67** | 두 판의 사건 3개 중 2개가 같다 |
| 거의 매 판 나오는 사건 | 14개 (출현율 97~100%) | 훈련소 일정 7개, 적금, 체력검정, 조용한 달, 사격 측정, 어머니 생신, "요즘 군대 편해졌다", 전투기술 경연 |
| 다른 사건이 남긴 결과를 조건으로 보는 사건 | **0개** | 모든 사건이 서로 독립 |
| 지연 결과(`later`)를 쓰는 사건 | **0개** | 엔진에는 기능이 있는데 콘텐츠가 안 쓴다 |
| 결정 형식 | 1가지 | 제목 → 본문 → 선택지 2~4개, 결과 한 줄 |

정리하면 원인은 셋이다.

1. **사건이 서로를 모른다.** 결정의 결과는 스탯 숫자(체력·멘탈 ±n)로만 남고, "무슨 일이 있었는지"는 남지 않는다. 그래서 뒤의 사건이 앞의 사건을 이어받을 수 없다.
2. **매 판 같은 풀에서 같은 확률로 뽑는다.** 육군 병사의 후보 풀은 사실상 고정이라, 판이 바뀌어도 비슷한 사건이 비슷한 빈도로 나온다.
3. **같은 형식이 반복된다.** 모든 순간이 "모달 → 선택 → 한 줄 결과"라 내용이 달라도 리듬이 같다.

## 2. 목표와 지표

**목표**
- 판마다 그 판만의 **이야기 줄기 2~3개**가 생기고, 줄기의 결말이 판마다 다르다.
- 앞의 선택이 뒤에서 **조건·문구·선택지**로 되돌아온다.
- 순간의 **형식**이 섞인다: 결정, 편지, 전화, 지켜보기만 하는 장면, 몇 달 뒤 돌아오는 결과.

**비목표**
- 분기 트리를 손으로 다 그리는 비주얼 노벨식 설계. 조합 폭발로 콘텐츠 작성이 불가능해진다.
- 자연어 생성(LLM). 정적 페이지·결정론(같은 시드 → 같은 판)을 유지한다.

**합격 지표** (자동 측정, `test/variety.test.js`로 고정)

| 지표 | 지금 | 목표 |
|---|---|---|
| 두 판의 사건 겹침 (Jaccard, 육군 병사) | 0.67 | **≤ 0.40** |
| 앞선 흔적을 읽는 사건 비율 (판당 발생 기준) | 0% | **≥ 40%** |
| 판당 되부르기(앞선 일을 언급하는 문구) | 0 | **≥ 4** |
| 판당 결말까지 간 줄기 | 0 | **≥ 2** |
| 연속 3개월 같은 형식 | 흔함 | **0** |

## 3. 핵심 개념 네 가지

### 3-1. 흔적 (mark)

사건과 결정이 끝날 때 **이름 붙은 흔적**을 남긴다. 스탯과 달리 "무슨 일이 있었는지"를 기억한다.

```js
S.marks = {
  boot_squad_leader: { ym: '2026-01' },          // 훈련소 분대장 훈련병을 했다
  gas_fled: { ym: '2026-01' },                   // 가스실을 뛰쳐나갔다
  ankle: { ym: '2026-01', v: 2 },                // 발목 통증 단계 (v: 세기)
  whistle: { ym: '2026-06', who: 'roomSenior' }, // 부조리를 신고했다 (대상 인물)
}
```

- 흔적은 **사실**만 담는다 ("신고했다"). 해석(평판·관계)은 기존 스탯·인물 관계치가 맡는다.
- 흔적은 사라지기도 한다 (`ankle` 치료 → 삭제). 남은 흔적은 전역 기록에 "이번 복무가 남긴 것"으로 보여 준다.

### 3-2. 줄기 (arc)

여러 달에 걸친 이야기. **단계(stage)** 가 있고, 흔적으로 열리고, 단계마다 갈라지며, 결말에서 흔적을 남긴다.

```
줄기 = { id, 여는 조건(흔적), 단계[], 결말[] }
단계 = 사건 또는 결정 하나 + "다음 단계까지 최소·최대 간격(개월)"
```

- 한 줄기는 3~5단계, 2~4개 결말. 다른 줄기의 흔적을 여는 조건으로 쓰면 **줄기끼리 엮인다** (예: 부상 줄기의 "의병 전역 고민" 단계는 부조리 줄기에서 고립된 상태면 선택지가 하나 더 생긴다).
- 판 시작(입영) 때 이번 판의 **주 줄기 2개**를 뽑아 둔다. 신분·군종·특기·마음속 이야기(heart 태그)로 가중치를 준다. 나머지 줄기는 흔적이 생기면 곁가지로 열린다.

### 3-3. 되부르기 (callback)

새 사건을 만들지 않고 **기존 사건의 문구를 흔적으로 바꾼다**. 적은 비용으로 "그때 그 일"이 계속 살아 있게 한다.

```js
// 자대 화생방 훈련 (기존 drill 사건)
t: has(S, 'gas_fled')
  ? '방독면을 쓰는 순간 훈련소 가스실이 떠올랐다. 이번엔 끝까지 버텼다.'
  : '방독면 착용 훈련. 정화통 냄새가 익숙해졌다.'
```

- 사건마다 `echo: [{ needs: 'gas_fled', t: '…' }, …]` 배열을 둔다. 맞는 흔적이 있으면 첫 번째 문구를 쓴다.
- 인물도 되부른다: "훈련소에서 같이 화생방을 버틴 그 동기"처럼 같은 인물을 다시 등장시킨다.

### 3-4. 연출 감독 (director)

지금은 매달 "사건 1~2개 + 결정 최대 1개"를 무작위로 뽑는다. 감독은 그 전에 **이번 달의 박자(beat)** 를 먼저 정한다.

| 박자 | 내용 | 형식 |
|---|---|---|
| 줄기 진행 | 진행 중인 줄기의 다음 단계 | 결정 또는 장면 |
| 되부르기 | 흔적을 언급하는 일상 사건 | 로그 한 줄 |
| 일상 | 계절·부대·인물 사건 | 로그 한 줄 |
| 위기 | 큰 사건 (사고·탈영·부상) | 결정 + 이어지는 장면 |
| 숨 고르기 | 아무 일 없음, 대신 편지·전화·사진 한 장 | 편지/전화 |

규칙:
1. **긴장도 곡선**: 긴장도 값(0~100)을 두고, 위기·결정은 올리고 숨 고르기는 내린다. 너무 오래 높으면 숨 고르기, 너무 오래 낮으면 줄기 진행이나 위기를 고른다. 복무 진행률에 맞춘 목표 곡선(입영 직후·일병 말·전역 직전에 봉우리)을 따른다.
2. **형식 반복 금지**: 직전 2개월과 같은 형식은 고르지 않는다.
3. **줄기 간격**: 줄기 단계마다 "최소 간격"이 있어서 한 줄기가 몰아서 끝나지 않는다. "최대 간격"을 넘기면 감독이 그 줄기를 우선한다.
4. 박자를 정한 뒤 고르는 건 지금의 `chooseFeed` 그대로 (박자에 맞는 후보로만 좁혀서).

## 4. 형식 다양화

모든 순간이 모달일 필요는 없다. 형식을 5가지로 늘린다.

| 형식 | 화면 | 예 |
|---|---|---|
| **결정** | 지금의 모달 | 분대장 할래? |
| **연속 결정** | 모달 안에서 2단계. 첫 선택에 따라 두 번째 질문이 바뀐다 | 부조리 목격 → "누구에게?" → "이름을 밝힐까?" |
| **편지·전화** | 편지지/통화 화면. 읽고 답장 한 줄을 고른다 | 연인의 편지, 어머니 전화 |
| **장면** | 선택 없이 2~3줄 서술 + 흔적만 남김 | 맞선임 전역식, 첫 눈 오는 날 제설 |
| **돌아오는 결과** | 몇 달 전 선택의 결과가 "그때 …한 덕에" 로그로 돌아옴 | 적금, 신고, 자격증 |

- 잠긴 선택지(조건 미달)도 이유와 함께 보여 준다 — `docs/02` §4 규칙 3. 흔적이 선택지를 여는 순간이 플레이어에게 보인다 ("훈련소 분대장 경험 — 이 선택지가 열렸습니다").

## 5. 육군 병사 기준 줄기 예시 (1차분 8개)

화살표는 단계, `[ ]`는 결정, `→ 흔적`은 남기는 흔적.

**A. 눈에 띈 훈련병** — 여는 조건: `boot_squad_leader` 또는 훈련소 사격 특등
1. 자대 전입: 행보관이 "훈련소 분대장 했다며?" 하고 이름을 기억한다 (되부르기)
2. 상병 진급 무렵 [분대장 추천 수락 / 거절]
3. 수락 → 후임이 사고를 친다 [감싼다 / 보고한다] → `squad_leader` + 결말: 모범 분대장 포상 · 책임 징계 · 후임과 평생 친구
4. 거절 → 다른 동기가 분대장 → 그 동기와의 관계 줄기로 이어짐

**B. 가스실의 기억** — 여는 조건: `gas_fled`
1. 자대 화생방 훈련: 선임이 "너 훈련소에서 튀었다며" (되부르기)
2. [그냥 웃는다 / 다시 해 보겠다고 자원한다]
3. 자원 → 화생방 경연 대표 → 결말: 극복(멘탈↑, 흔적 삭제) · 다시 실패(놀림거리, 관계↓)

**C. 시큰한 발목** — 여는 조건: `ankle` (훈련소에서 참았다)
1. 2~4개월 뒤 행군 때 다시 붓는다 [의무대 / 참는다]
2. 참으면 `ankle.v` +1, 의무대면 "또 아프냐" 눈치 (관계↓)
3. `v ≥ 2` → 국군병원 외진 [수술 / 버틴다]
4. 결말: 완치 · 만성 통증 안고 전역 · 의병 전역(부적합 심사 `unfit_review`로 연결)

**D. 마음의 편지** — 여는 조건: `abuse_seen`에서 신고 선택 → `whistle`
1. 조사 (장면): 간부 면담, 가해 선임은 다른 생활관으로
2. 1~2개월 뒤 [보복의 기미를 알린다 / 참는다]
3. 결말: 부대 분위기 바뀜(부조리 지수↓) · 고립(멘탈↓, 동기만 남음) · 가해 선임 전역 날 사과 (장면)

**E. 기다려 줄까** — 여는 조건: 연인 있음 (heart의 연인 태그면 주 줄기 가중↑)
1. 훈련소 인편 (기존 `boot_letter` → 흔적 `letter_lover`)
2. 첫 면회/외박 [어디 갈까] → 3. 연락 뜸해짐 (기존 `bond_gomsin_crisis`) → 4. 결말: D-100 기념일 · 이별 · 전역날 마중

**F. 같은 날 입대한 동기** — 항상 열림 (`peer` 인물)
1. 훈련소에서 같이 버틴 동기가 같은 자대로 (되부르기)
2. 동기가 힘들어한다 [들어 준다 / 바쁘다]
3. 들어 줬다면 → 동기 탈영 위기 때 동기를 붙잡을 수 있음 (기존 `desertion_other`와 엮임)
4. 결말: 전역 후에도 연락하는 동기 · 먼저 의병 전역한 동기 · 연락 끊김

**G. 자격증 하나** — 여는 조건: 취미가 자격증·어학·수능, 또는 heart 공부 태그
1. 시험 접수 [주말 근무와 겹친다 — 바꿔 달라 한다 / 포기]
2. 합격 → 보직 변경 제안 또는 포상휴가 (돌아오는 결과) → 결말: 자격증 n개 · 불합격 후 재도전

**H. 짬 바뀌는 날** — 항상 열림 (`senior`, `roomSenior` 인물의 `ahead`로 전역 시점 결정)
1. 무서운 맞선임 전역 (장면) → 2. 내가 맞선임이 됨 [물려받은 관행을 이어 간다 / 끊는다] → 3. 결말: 후임에게 존경 · 부조리 대물림 (D 줄기 흔적과 교차)

판 시작 때 주 줄기 2개를 뽑으면 A·C·D·G 같은 조합이 판마다 달라지고, 흔적에 따라 곁가지(B·E·F·H)가 붙는다. 8개 중 2~3개만 깊게 가므로 **판마다 다른 이야기**가 된다.

## 6. 데이터 형

기존 사건 형식(`id, kind, when, c, w, gap, max, build, apply, run`)에 필드 다섯 개만 더한다. 엔진은 작게 유지한다.

```js
{ id: 'arc_gas_02_volunteer', kind: 'decision',
  arc: 'gas', stage: 2,                 // 줄기·단계 (없으면 일반 사건)
  needs: ['gas_fled'],                  // 흔적 조건 (c보다 먼저 검사)
  gapMin: 2, gapMax: 5,                 // 직전 단계 이후 간격(개월)
  format: 'decision',                   // decision | chain | letter | scene | return
  echo: [{ needs: 'squad_leader', t: '…' }],
  build: (S) => ({ … }),
  apply: (S, k) => ({ t, fx, mark: { set: { gas_brave: {} }, del: ['gas_fled'] }, arc: { next: 3 } | { end: 'overcome' } }),
}
```

- `out.mark`: 흔적 추가·삭제. `out.arc`: 다음 단계로 / 결말로.
- 줄기 상태: `S.arcs = { gas: { stage: 2, ym: '2026-05', end: null } }`.
- 감독 상태: `S.tension`, `S.formats` (최근 형식 3개).
- 판 시작 주 줄기: `S.mainArcs = ['gas', 'cert']` — 입영 시 `rand(S)`로 (결정론 유지).
- 모든 값은 `S` 안에 있으므로 저장·공유 링크(시드 + 결정 기록) 구조는 그대로다.

## 7. 콘텐츠 작성 규칙 (테스트로 강제)

1. **모든 결정은 흔적을 하나 이상 남긴다.** 스탯만 바뀌는 결정은 금지 — `test/narrative.test.js`가 `apply` 결과를 전 선택지에 대해 검사한다.
2. **모든 흔적은 누군가 읽는다.** `mark.set`으로 만든 흔적 id가 다른 사건의 `needs`/`echo`에 한 번 이상 나와야 한다 (고아 흔적 금지).
3. **줄기는 끝난다.** 모든 줄기에 결말이 2개 이상, 모든 단계에서 결말까지 가는 경로가 있다 (그래프 검사).
4. 문구 속 인물은 `{senior}` 같은 자리표시자로만 쓴다 (기존 `fmt` 규칙) — 같은 인물이 판 내내 일관된다.

## 8. 화면에서 달라지는 것

- **로그**: 되부르기 줄은 앞선 일의 날짜를 작게 붙인다 ("← 2026년 1월 훈련소").
- **신원 카드**: "지금 이어지는 이야기" 칸에 진행 중인 줄기 이름 2~3개 (결말 전엔 단계만, 내용은 숨김).
- **전역 기록**: "갈림길" 절 — 판에서 고른 주요 선택과 그 결과가 이어진 모습을 줄기별로 한 줄씩 ("훈련소에서 손을 들었다 → 분대장 → 후임을 감쌌다 → 모범 분대장"). 같은 시드로 다시 할 때 "다른 길"을 궁금하게 만드는 장치.

## 9. 단계별 진행 (마일스톤)

| 단계 | 내용 | 완료 기준 |

| N1 | 엔진: `marks`·`needs`·`echo`·`out.mark`, 측정 스크립트를 `test/variety.test.js`로 | 기존 테스트 통과 + 지표 측정 자동화 |

## 10. 정해야 할 것

1. **주 줄기를 플레이어가 알게 할까?** 입영 때 "이번 복무의 이야기" 두 개를 보여 줄지(기대감), 숨길지(발견의 재미). 기본안: 숨기고, 첫 단계가 열리면 신원 카드에 이름만 뜬다.
2. **결말의 무게**: 줄기 결말이 조기 전역(의병 전역 등)까지 갈 수 있게 할지. 기본안: C(부상)·D(부조리)만 허용.
3. **문구 분량**: 줄기 8개 × 4단계 × 선택지 2~3개 ≈ 결과 문구 80~100개 + 되부르기 20개. 리서치(`research/situations/`)를 바탕으로 쓰되 전부 `가정` 표시.
4. **긴장도 곡선 모양**: 봉우리 위치(입영 직후·일병 말·전역 직전)가 실제 체감과 맞는지 — 사용자 감수 필요.

## 11. 대상: 병사만

부사관·장교·준사관은 다루지 않는다(2026-10-16 결정). 간부 전용 사건(`events-cadre.js`)·장교 양성교육·장기복무 엔딩·간부 규칙 데이터(의무복무·급여·정년)는 삭제했다. `S.status`는 항상 `'soldier'`.

## 12. 지역

같은 군종·근무지라도 **어디서** 복무하느냐에 따라 겨울·외출·휴가·출동이 달라진다.

- **데이터:** `rules/env.json`의 `post.<군종>.<근무지>.places` — 지역마다 가중치 `w`, 서울까지 편도 `travel`(시간), `tags`. 전부 '가정'.
  - 육군: GOP(철원·화천·양구·인제·고성·연천·파주), 해안, 전방 일반, 후방, 사령부
  - 해군: 대형 함정(동해·평택·목포·제주·부산), 고속정(평택 서해·동해·목포), 육상 기지(진해·평택·부산·포항), 도서(울릉도·백령도)
  - 공군: 비행단 9곳, 산꼭대기 사이트 3곳, 사령부·지원 3곳
  - 해병대: 서북도서(백령도·연평도), 본토(포항·김포·강화·제주)
- **태그:** cold 혹한 · snow 폭설 · sea 바다 · island 배로만 · nll 접적 해역 · capital 수도권 · city 큰 도시 · town 군인 마을 · tourist 관광지 · jet 비행단 · mountain 산꼭대기 · ship 함정 · small 소형 함정 · cherry 진해
- **엔진:** `drawEnv`가 근무지 다음에 지역을 뽑아 `S.env.place`에 둔다. 사건의 `when.place: [태그 또는 근무지 id]` 중 하나라도 맞으면 후보가 된다(`placeIs`).
- **사건 (`content/events-place.js`, 25개):**
  - 혹한 근무(동상 흔적 `frostbite`)·폭설 제설
  - 배 결항으로 휴가 지연(`ferry_stuck`)·해무 고립·접적 해역 경계 태세
  - 첫 출항 멀미(`seasick`/`sea_legs` — 이후 출동 문구가 갈린다)·출동·입항일·좁은 침실
  - **육상 근무 전환 결정:** 성공하면 근무지가 바뀌고 함정 사건이 멈춘다(`ship_off`)
  - 비행단 소음·활주로 이물질 수거·비상 출격, 산꼭대기 고립·운해, 해안 경계, 철책, 대민 지원, 행사 동원, 진해 군항제
  - 외출(군인 마을 / 큰 도시 / 관광지)·가까운 집 면회·먼 휴가길
- **기존 사건의 지역 문구:** 조용한 달·훈련·명절 휴가·어머니 생신이 지역을 읽는다(흔적 문구가 먼저).
- **측정 (병사, 자동 판):** 지역 사건은 판당 3~7개. 서로 다른 지역에서 복무한 두 판의 겹침(Jaccard)은 0.57 안팎으로, 같은 지역 두 판의 0.67보다 낮다.
