# 05. 시대와 재미: 판마다 다른 군 생활

> 한 줄: **언제 들어갔느냐가 어떤 군 생활이었는지를 정한다.** 1998년 GOP와 2024년 공군 BX병은 같은 게임 안에서 완전히 다른 이야기여야 한다.

## 1. 왜 재미가 없었나 (2026-10-18 진단)

같은 "통계 추첨 + 시간 흐름 + 결정" 형식인데, 재미의 원천이 비어 있었다.

| 재미의 원천 | 이전 상태 |
|---|---|
| 추첨 결과의 폭 | 77.8%가 육군, 다들 18개월 뒤 병장 만기 전역. 주특기는 분위기만 바꾼다 |
| 끝을 모르는 긴장 | 전역일이 첫 화면에 찍혀 있다 |
| 고민되는 선택 | 한쪽이 숫자로 명백히 이득 (집중한다 +4 / 대충 −4) |
| 숫자의 의미 | `fx` 약 500개 중 mind 305개. 숫자가 결과로 이어지지 않는다 |
| 사람 | 이름 없는 "선임", 한 번 쓰고 끝 |
| 문체 | 백과사전체 ("탄약 한 발이 30kg에 달한다") |

## 2. 목표 (합격 기준은 테스트로 고정)

| # | 목표 | 합격 기준 |
|---|---|---|
| G1 | **시대 추첨**: 입대 연도(추첨, 고를 수 없음)가 복무기간·월급·휴대폰·부조리 기본값을 정한다 | 연도별 복무일수·월급이 `rules/era.json` 근거값과 일치 (`test/era.test.js`) |
| G2 | **시대 분위기**: 시대 구간마다 그 시절에만 있던 장면 | 구간마다 시대 한정 사건 8개 이상, 옛 시대일수록 부조리 사건 빈도↑ |
| G3 | **이름 있는 사람들**: 선임·동기·간부가 이름과 성격을 갖고 판 내내 다시 나온다 | 출생 연대에 맞는 이름, 인물 관계치가 결과를 바꾼다 |
| G4 | **양쪽 다 손해인 선택** | 딜레마 12개 이상, 모든 선택지에 대가(음수 효과 또는 관계 하락)가 있다 |
| G5 | **판마다 크게 갈린다** | 꼬리 사건 10개 이상. 200판(1995~2026 고르게)의 한 줄 요약이 60종 이상, 가장 흔한 한 줄 ≤ 10% |
| G6 | **같은 날 입대한 사람들**: 전역 화면에 같은 입영일의 다른 3명의 운명 | `cohort()` 결정론 |
| G7 | **썰 문체**: 근거는 옆에 두고 본문은 "그날 행보관이 말했다" 식 | 새 콘텐츠 전부 + 일상 사건 재작성 |

## 3. 시대 모델

- `rules/era.json` — `range`(추첨 연도 범위), `eras`(구간: id·라벨·설명·부조리 가산·진급 단계), `service`(군종별 입영일 → 복무개월·점진 단축), `pay`(연도별 계급 봉급), `phone`(휴대폰 사용 연표), `savings.match`(적금 매칭 비율).
- 엔진: `enlist`가 `S.era`를 정하고, 사건은 `when.era: ['e05', ...]`, `when.phone: true|false`로 시대를 거른다.
- 폐지된 보직(공관병 등)은 시대 조건 없이 그대로 둔다 (추억·신기함이 목적).
- 근거: `research/era-official.md`(제도·수치), `research/era-culture.md`(문화·장면).

## 4. 콘텐츠 규칙 (추가)

1. 실제 사건은 연도와 유형까지만. 피해자 실명·선정적 묘사 금지. 무거운 사건엔 도움 창구(HELP).
2. 부조리 장면은 "그 시절엔 그게 당연했다"는 구조를 보여 주되, 미화하지 않는다. 플레이어는 당하는 쪽, 보는 쪽, 물려주는 쪽이 될 수 있다.
3. 인물은 `{senior}`(역할+이름), `{senior.name}`(이름만) 자리표시자로만 부른다.

## 7. 짬 규칙 (2026-10-19)

계급이 허락하는 것만 할 수 있다. 규정엔 없는 불문율 6개(`content/events-rank.js`):
- 눕기·PX·사지방·각 잡기 — 육군이 2015년 직접 반박한 '카더라' 목록 [S_cul_24]
- 샤워 순서 — 해병대 증언 [S_cul_12]
- 깔깔이 — 가정

어기면 편하지만, 걸리면 쿠사리가 나 혼자로 끝나지 않는다:
- 나만 혼남
- 동기 전체 집합 (연대책임)
- 맞선임이 "애 교육을 어떻게 시킨 거냐"며 깨짐

동기가 어겨 단체로 구를 때 "누가 그랬냐"에 답하는 딜레마도 있다. 이름을 댄다, 입을 다문다, 내가 했다고 한다 중에 고른다. 짬이 차면 처음으로 대낮에 눕는 장면이 나온다.

나오는 빈도와 걸리는 확률은 부조리 지수에 비례한다 (150판씩, 결정은 무작위):

| 입대 연도 | 위반 상황/판 | 걸림 : 안 걸림 | "누가 그랬냐" |
|---|---|---|---|
| 1998 | 1.9 | 97 : 45 | 44% |
| 2016 | 1.4 | 52 : 55 | 33% |
| 2024 | 0.4 | 13 : 24 | 14% |

### 역부조리 — 짬이 차도 편하지 않다

신고 창구가 넓어진 2014-08(병영문화혁신) 이후, 상병이 되면 이번엔 위가 아래 눈치를 본다.
- 근거: 헬프콜 신고·상담이 2014년 17,258건에서 2020년 58,378건으로 늘었다 [S_era_6].
- 근거: 후임들의 과장된 마음의 편지가 조사 끝에 혐의없음으로 끝난 사례가 있다 (로톡, 후기급 1건).
- 나머지는 가정이다.

| 장면 | 내용 |
|---|---|
| 시켜야 하는데 (결정) | 청소를 다시 시킬지 고른다. 지적하면 마음의 편지에 이름이 오를 수 있다. 부탁하면 동기가 비웃는다. 내가 하면 상병이 걸레를 든다 |
| 반납 안 한 폰 (결정, 휴대폰 시대) | 당직에게 보고하면 후임과는 끝이다. 따로 불러 말하면 편지에 오를 수 있다. 못 본 척했다가 걸리면 생활관 전체가 사용 정지다 |
| "야" 하고 부른 순간 | 폭언 교육이 떠올라 말을 고친다 |
| 마음의 편지 걷기 사흘 전 | 상병들이 갑자기 친절해지고 냉동 만두가 돈다 |
| 낀 세대 | 이병 땐 짬 규칙을 다 지켰는데, 상병이 되니 후임이 대낮에 누워 있다 |

마음의 편지에 오르면 대부분 두 달 조사 뒤 혐의없음으로 끝나고, 20%는 견책이다.

| 입대 연도 | 역부조리/판 | 편지에 오른 판 |
|---|---|---|
| 2003 이전 | 0 | 0% |
| 2013 (상병 때 2014-08을 넘긴다) | 1.7 | 3% |
| 2016 | 2.0 | 2% |
| 2024 | 2.7 | 16% |

## 8. 큰 이슈 — 평탄한 군 생활 깨기 (2026-10-19)

진단:
- 기분 곡선이 거의 일직선으로 올랐다 (첫 선택지만 고르면 4개월 단위 중앙값이 53→55→56→60→64→68).
- 두 달 새 8 이상 꺼지는 판은 27%뿐이었다.
- 원인 1: 휴가 여운(원동력)이 매달 멘탈 +2였다. 남은 휴가가 몰리는 말년엔 거의 매달 켜져 있었다.
- 원인 2: 멘탈이 30·20 아래로 떨어져야 열리는 탈영·부적합 심사가 사실상 열리지 않았다.

바꾼 것 (`content/events-crisis.js`):
- **위기 일정**: 판마다 1~3번 큰 이슈가 반드시 터진다. 옛 시대·나쁜 부대일수록 많다. 시점은 자대 3개월째부터 전역 2개월 전 사이에 고르게 퍼진다. 별도 난수 줄기를 써서 다른 추첨은 그대로다.
- **위기 6종**: 모든 선택지가 크게 잃는다.

| 위기 | 갈림길 |
|---|---|
| 탄피 하나 | 밤샘 수색과 출타 통제 / 몰래 채우기 (걸리면 영창·군기교육대) / 내 실수로 보고 |
| 창고 뒤 (구타) | 신고하면 투명인간이 될 수 있다 / 참으면 멘탈 −18 / 되받아치면 영창·군기교육대, 15%는 군사재판 |
| 내 주머니의 지갑 (누명) | 버티면 낙인 / 남을 지목하면 생활관이 갈라진다 / 자백하면 징계 |
| 막차를 놓쳤다 | 사실대로 말하면 휴가 단축 / 꾀병은 들키면 영창 / 택시는 월급이 날아간다 |
| 무릎 | 수술 / 의병 전역 심사 (30%) / 파스로 버티기 |
| 집에서 온 연락 | 청원휴가 / 의가사 전역 (30%) / 모른 척 |

- 영창은 2020-08 폐지 → 그 뒤엔 군기교육대.
- 위기로 멘탈이 꺼지면 기존 탈영(→ 군사재판)·부적합 심사(→ 강제 전역)가 실제로 열린다.
- 휴가 여운은 매달 +1로 줄였다.
- 말년의 그늘 3종: 전역이 무섭다, "나와서 뭐 할 거냐", 친구들 대화가 낯설다.

결과 (300판, 1995~2026 고르게):

| | 첫 선택지만 (이전 → 지금) | 무작위 선택 (이전 → 지금) |
|---|---|---|
| 기분 중앙값 (4개월 단위) | 53 55 56 60 64 68 → 53 51 49 50 53 57 | 54 55 54 54 56 56 → 54 51 47 44 44 47 |
| 두 달 새 8 이상 꺼지는 판 | 27% → 75% | 48% → 78% |
| 조기 종료 | 5% → 8% | 8% → 23% |
| 영창·군기교육대 | 2% → 1% | 4% → 24% |

무작위 선택에서 조기 종료가 23%인 건 위험한 선택지를 3분의 1 확률로 고르기 때문이다. 안전하게 가면 8%다.

## 9. 내리막 — 애써도 무너지는 판, 그린캠프 (2026-10-19)

`content/events-spiral.js`

내리막에 들어서는 길:
- 부적응 성향: 판 시작 때 3~12%가 숨은 추첨으로 정해진다 (부조리가 심할수록 높다). 평균 8개월쯤 지나 시작된다.
- 큰 이슈로 멘탈이 11 아래로 떨어지면 누구나 들어선다.

들어서면:
- 매달 멘탈이 −4 빠진다 (`S.flags.spiral`, 엔진 `applyMonthly`).
- 무너지는 장면 5개가 나온다: 밥이 모래 같다, 점호 대답, 쓰다 만 편지, 초소의 어둠, 유리벽.
- **버텨 보려고** (결정, 최대 3번). 노력은 잠깐만 듣고 내리막은 멈추지 않는다.
  - 새벽 달리기
  - 동기에게 털어놓기 (말이 돌 수 있다)
  - 일에 파묻히기
  - 상담관 (관심병사가 된다, 내리막이 −2로 늦춰진다)

바닥 — **그린캠프**:
- 내리막 3개월 이상, 그리고 멘탈 10 미만 (상담받았으면 18 미만)일 때 온다.
- 원대 복귀: 멘탈 +18. "거기 다녀온 애"가 된다. 40%는 내리막이 남는다.
- 현역복무 부적합 심사: 50%는 강제 전역.
- 그린캠프 도입 연도는 미확인이다. 2010년 이전 판은 국군병원 정신건강의학과로 간다.
- 근거:
  - 그린캠프는 복무 부적응 병사를 위한 집단 심리사회 치료다 [koreascience JAKO201025247234263].
  - 3주 9회기 프로그램 사례가 있다 [earticle A175611].
  - 2014년 육군은 "자살 우려자 수용소에서 치유 중심으로" 바꿨다고 했다 [세계일보 2014-08-12].

같이 조정한 것:
- 탈영 결정은 멘탈 30 → 22 미만에서 열린다.
- 부적합 심사는 20 → 15 미만에서 열린다 (그린캠프를 다녀온 판 제외). 골짜기가 깊어져서 예전 기준이면 너무 자주 열렸다.

결과 (400판, 첫 선택지만 / 무작위 선택):

| | 첫 선택지만 | 무작위 |
|---|---|---|
| 내리막 | 19% | 25% |
| 그린캠프 | 12% | 17% |
| 끝이 시작보다 8 이상 낮은 판 | 15% | 55% |
| 조기 종료 | 7% | 24% |
