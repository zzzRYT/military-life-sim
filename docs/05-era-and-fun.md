# 05. 시대와 재미: 판마다 다른 군 생활

> 한 줄: **언제 들어갔느냐가 어떤 군 생활이었는지를 정한다.** 1998년 GOP와 2024년 공군 BX병은 같은 게임 안에서 완전히 다른 이야기여야 한다.

## 1. 왜 재미가 없었나 (2026-10-18 진단)

같은 "통계 추첨 + 시간 흐름 + 결정" 형식인데, 재미의 원천이 비어 있었다.

| 재미의 원천 | 이전 상태 |
|---|---|
| 추첨 결과의 폭 | 77.8%가 육군, 다들 18개월 뒤 병장 만기 전역. 주특기는 분위기만 바꾼다 |
| 끝을 모르는 긴장 | 전역일이 첫 화면에 찍혀 있다 |
| 고민되는 선택 | 한쪽이 숫자로 명백히 이득 (집중한다 +4 / 대충 −4) |
| 숫자의 의미 | `fx` 약 500개 중 mind 305개. 숫자가 결과로 이어지지 않는다 |
| 사람 | 이름 없는 "선임", 한 번 쓰고 끝 |
| 문체 | 백과사전체 ("탄약 한 발이 30kg에 달한다") |

## 2. 목표 (합격 기준은 테스트로 고정)

| # | 목표 | 합격 기준 |
|---|---|---|
| G1 | **시대 추첨**: 입대 연도(또는 직접 고른 해)가 복무기간·월급·휴대폰·부조리 기본값을 정한다 | 연도별 복무일수·월급이 `rules/era.json` 근거값과 일치 (`test/era.test.js`) |
| G2 | **시대 분위기**: 시대 구간마다 그 시절에만 있던 장면 | 구간마다 시대 한정 사건 8개 이상, 옛 시대일수록 부조리 사건 빈도↑ |
| G3 | **이름 있는 사람들**: 선임·동기·간부가 이름과 성격을 갖고 판 내내 다시 나온다 | 출생 연대에 맞는 이름, 인물 관계치가 결과를 바꾼다 |
| G4 | **양쪽 다 손해인 선택** | 딜레마 12개 이상, 모든 선택지에 대가(음수 효과 또는 관계 하락)가 있다 |
| G5 | **판마다 크게 갈린다** | 꼬리 사건 10개 이상. 200판(1995~2026 고르게)의 한 줄 요약이 60종 이상, 가장 흔한 한 줄 ≤ 10% |
| G6 | **같은 날 입대한 사람들**: 전역 화면에 같은 입영일의 다른 3명의 운명 | `cohort()` 결정론 |
| G7 | **썰 문체**: 근거는 옆에 두고 본문은 "그날 행보관이 말했다" 식 | 새 콘텐츠 전부 + 일상 사건 재작성 |

## 3. 시대 모델

- `rules/era.json` — `range`(추첨 연도 범위), `eras`(구간: id·라벨·설명·부조리 가산·진급 단계), `service`(군종별 입영일 → 복무개월·점진 단축), `pay`(연도별 계급 봉급), `phone`(휴대폰 사용 연표), `savings.match`(적금 매칭 비율).
- 엔진: `enlist`가 `S.era`를 정하고, 사건은 `when.era: ['e05', ...]`, `when.phone: true|false`로 시대를 거른다.
- 폐지된 보직(공관병 등)은 시대 조건 없이 그대로 둔다 (추억·신기함이 목적).
- 근거: `research/era-official.md`(제도·수치), `research/era-culture.md`(문화·장면).

## 4. 콘텐츠 규칙 (추가)

1. 실제 사건은 연도와 유형까지만. 피해자 실명·선정적 묘사 금지. 무거운 사건엔 도움 창구(HELP).
2. 부조리 장면은 "그 시절엔 그게 당연했다"는 구조를 보여 주되, 미화하지 않는다. 플레이어는 당하는 쪽, 보는 쪽, 물려주는 쪽이 될 수 있다.
3. 인물은 `{senior}`(역할+이름), `{senior.name}`(이름만) 자리표시자로만 부른다.

## 5. 결과 (2026-10-18, 320판 · 1995~2026 고르게 · 결정은 무작위)

| 지표 | 이전 | 지금 |

| 사건 수 | 175 | 293 (시대 장면 68 · 시대 딜레마 25 · 인물 11 · 꼬리·역사 13) |
| 모든 선택지에 대가가 있는 딜레마 | — | 새 딜레마 29개 + 기존 결정 63개 재조정 |
| 판의 한 줄 요약 종류 | — | 135종, 가장 흔한 것 6% |

| 판당 되부르기 | 0 | 6.25줄 |
| 판당 시대 장면 | 0 | 6.7개 |

추가로 들어간 장치: 입대 연도 추첨 카드, 진급·전역 전날의 수첩 멈춤(전역 기록에서 돌려받음), 같은 날 입대한 40명 중 내 위치, 결과 복사, 다음 결정까지 빨리 감기.

## 6. 사용성 검증 (2026-10-19, 헤드리스 Chrome으로 수동 플레이 끝까지 · 데스크톱 1280px / 모바일 390px)

| 발견 | 고친 것 |
|---|---|
| 신체등급 7급(재검)·4~6급(보충역·면제)인데 현역으로 복무 | 7급은 재검으로 1~6급 재추첨. 4급은 2022년부터 현역 자원, 그 전과 5·6급은 판정 화면에서 끝 → "다시 태어나기" |
| 추첨 결과가 2.2초 만에 사라짐 (시대 설명·연기 이력을 읽을 수 없음) | "입소한다" 버튼을 눌러야 시작 |
| 시대를 바꾼 판의 첫 로그가 엉뚱한 해(2025-01) | 생년을 다시 계산할 때 판정 로그 연월도 갱신 |
| 훈련소에서 자대 인물(성격 평가까지)이 미리 보임 | 자대 배치 전엔 "자대에 가면 만나게 됩니다" |
| 주특기 설명에 깨진 링크 문자열 `(../../branches-mos.md)` | 데이터에서 제거 (하나는 잘려 있어 정밀 치환) |
| 주마등이 결정을 전부 넣어 33장(약 53초) | 주마등은 14장 (입소·마지막 → 큰 일 → 되부르기 → 결정). 연대기는 전체 유지 |
| 전역 보고서 맨 위가 "같은 특기를 뽑을 확률 1.4%" | 맨 위에 이 군 생활의 한 줄 → 같은 날 입대한 사람들 → 수첩, 숫자는 아래로 |
| 선택의 결과가 숫자로 안 보임 | 로그 줄마다 변화 칩 (멘탈 −8 · 동기 박민준 +25) |
| 한 줄 요약이 평가 포상·휴가·말년 결정으로 쏠림 | 가장 크게 흔든 결정(스탯+관계 변화량)을 고름 → 320판 200종, 최다 2.8% |
| 같은 날 입대한 세 명의 한 줄이 겹침 | 서로·나와 겹치지 않는 줄을 고름 |
| 모바일에서 장면·로그가 신원 카드 아래로 밀림 | 860px 이하에선 장면·로그가 먼저 |
| 추첨 카드 5장이 4칸 그리드라 한 장만 줄바꿈 | 자동 맞춤 그리드 |
| 월급 `+73500원` | `+73,500원` |
| 새로고침·탭 종료 시 15분 판이 날아감 | 달마다 자동 저장, 시작 화면에 "이어하기" |
| 업데이트한 규칙 JSON이 브라우저 캐시로 안 바뀜 | 규칙 파일은 매번 재검증해서 받음 |
| 끝나면 "새로운 인생"뿐 | "그 해, 다른 인생" (입대 연도 유지) |
| 2004년 입대자에게 '무인항공정찰기운용'·드론 같은 최근 특기가 나옴 | 특기 12개에 도입 시점(`since`, 대부분 가정) — 그 전 입대자에겐 그때 있던 특기로 다시 뽑는다. 헌병 → 군사경찰(2020-06) 특기는 그 전엔 옛 이름 |
| 시작 화면에 입대 연도를 고를 수 있다는 안내가 없음 | 안내 문구에 시대 차이와 "내가 입대한 해" 선택을 적음 |
| 수첩은 마우스로만 닫힘, 적은 말이 어디 쓰이는지 모름 | Ctrl/⌘+Enter로 덮기, "전역하는 날 돌려받습니다" 안내 |

추가 확인: 라이트 모드 화면 이상 없음, 전역 화면의 같은 날 입대자 40명 계산 0.05~0.11초.

리듬 측정 (120판): 수동 모드에서 멈추는 순간(결정·수첩)이 월 1회 꼴, 가장 긴 공백 4개월 — 손댈 필요 없음.


남은 것: 특기 도입 연도는 공개 보도 기준 추정이라 `rules/soldier-mos.json`의 `sinceSrc`에 가정으로 표시했다. 병과별 신설 연도 공식 자료를 찾으면 교체.
