# 02. 디자인 문서 (UX·UI)

시간 단위는 "**복무·월(月)·D-day**"다.

---

## 1. 톤

- 담담한 기록체. "~했습니다." 과장된 밈이나 군대 유머는 쓰지 않는다. 웃긴 순간은 사건 자체에서 나오게 둔다.
- 서류 모티프: 입영 통지서, 배치 통지서, 전역증. 판의 시작을 알리는 카드는 **배치 통지서**다.
- 숫자에는 근거가 함께 붙는다. 근거가 없는 수치는 표시하지 않거나 `추정` 배지를 단다.

## 3. 메인 화면 (S5)

```
┌──────────────────────────────────────────────────────────────────┐
│ D-312  · 일병 · 2027년 3월 · 1개월 ≈ 40초   ❚❚ 1× 2× 4× 8×  다음 결정까지 » │
│ ███████████░░░░░░░░░░░░ 복무 진행 38%                       자동 결정 ○ │
├───────────────┬───────────────────────────────┬──────────────────┤
│ 신원 카드       │  [픽셀 장면: 생활관/연병장/함정]   │ 같은 날 입영한 동기 │
│ 이름·군번·군종   │  이번 달의 초점: 체력│학습│휴식│관계 │  4명의 현재 상태    │
│ 특기·부대(상급)  │                               │                  │
│ 계급 배지       │  복무 기록 (로그 피드)            │ 복무 지도          │
│ 체력 ▇▇▇▇░     │  3월 · 혹한기 훈련이 끝났습니다.   │ (한 칸 = 1개월)    │
│ 멘탈 ▇▇▇░░     │       자료 · 군인복무기본법 …     │                  │
│ 숙련 ▇▇░░░     │  3월 · 결정: 적금 55만 원 → …    │ 휴가 잔여 14일      │
│ 관계 ▇▇▇▇░     │                               │ 다음 진급 4월 1일   │
│ 돈: 적금·잔고   │                               │                  │
└───────────────┴───────────────────────────────┴──────────────────┘
```

- **상단 바**: 가장 큰 숫자로 `D-day`를 둔다. 서브 줄에는 계급·연월·배속 기준 1개월 길이를 보여준다. 진행 바는 복무 진행률을 나타낸다.
- **시간 조작**: 멈춤, 1×~8×, `다음 결정까지 »`, `자동 결정`. 결정이 열리면 시간이 자동으로 멈춘다.
- **이번 달의 초점**: 상시 칩 4개(체력·학습·휴식·관계)이고 방향 화살표로만 효과를 표기한다. 고르지 않으면 자동으로 정해진다. 공군은 훈련소 기간에 학습을 고르면 성적이 오르고 자대 배정에 반영된다(서사로 연결).
- **복무 지도**: 한 칸이 1개월이다. 진할수록 괜찮았던 달이고, 칸 아이콘은 `진`(진급), `휴`(휴가), `훈`(훈련), `!`(사건)이다.
- **동기 4명**: 같은 날 입영한 가상의 4명이다. 각자 다른 신분·군종으로 추첨돼 복무하고, 우측 패널에서 현재 계급과 상태를 보여준다.
- **모바일**: 1열로 쌓고, 상단 바와 로그를 우선한다. 좌·우 패널은 탭(신원 / 동기 / 지도)으로 접는다. 좌우 여백은 16px이고 가로 스크롤은 없다.

## 4. 결정 모달 문법 (S6)

```
┌ 중대 결정 · 상병 · 2027년 9월 ───────────────────────┐
│ 적금, 얼마나 넣을까?                                   │
│ 월급 120만 원. 지난달 PX와 외출에 38만 원을 썼습니다.        │
│ ▌자료 · 납입 원금의 100%를 정부가 매칭 (국방부, 2025)       │
│                                                     │
│ [1] 55만 원 꽉 채운다   · 전역 때 목돈↑ · 쓸 돈이 빠듯하다     │
│ [2] 30만 원만 넣는다    · 적당히                          │
│ [3] 안 넣는다          · 지금이 편하다 · 매칭 0원            │
│ [–] 다른 은행 계좌 추가  · 계좌당 30만 원 한도 (이미 2계좌)   │
│                                   잠깐 내려 두기 ▾      │
└─────────────────────────────────────────────────────┘
```

규칙:
1. 구성은 제목 → 상황 본문 → 근거 줄(녹색 띠, 출처 약칭) → 번호 카드 2~5개 순서다.
2. 카드의 부가 설명에는 **비용(돈·휴가일·점수)과 효과 방향**만 쓴다. 수치 확률은 결과가 나온 뒤에 공개한다. 사전에는 "가능성 반반쯤", "높은 편" 같은 정성 표현을 쓴다.
3. 조건이 안 되는 선택지도 숨기지 않는다. `–` 표시와 함께 사유·해금 조건을 보여준다("통산 2년 연기를 모두 썼습니다").
4. 같은 결정이 상황에 따라 다시 나오고, 문구도 달라진다(휴가 시기, 적금, 장기복무).
5. 결과는 즉시 로그 한 줄로 남긴다. 몇 달 뒤 돌아오는 **지연 결과**는 별도 로그로 쓴다("그때 아낀 덕에 전역 때 1,980만 원이 모였습니다").
6. 숫자 키 단축키를 지원한다. 텍스트 입력칸에 포커스가 있으면 단축키를 끈다.
7. 자동 결정은 카운트다운과 함께 **무난한 기본값**을 강조 표시한다. 기본값은 "평균적인 선택"으로 지정한다.

## 5. 잠시 멈춤 (S7)

| 시점 | 질문 |
|---|---|
| 입영 첫날 밤 | "오늘 가장 그리운 건 무엇인가요?" |
| 100일 | "처음과 달라진 것 하나는?" |
| 상병 진급 | "지금 후임에게 해 주고 싶은 말은?" |
| 전역 D-30 | "나가서 가장 먼저 하고 싶은 일은?" |

- 입력은 선택이다. 적은 글은 로그에 인용구로 남고 엔딩 카드에 다시 나온다.
- "다음부터 띄우지 않기" 옵션을 둔다.

## 6. 엔딩 (S8)

1. 마지막 달 다이얼로그 → 회상 슬라이드 → 전역 기록 페이지.
2. **공유 카드**: 신분·군종·특기·최종 계급, 복무 일수, 적금 만기액, 동기 4명의 결말, 큰 숫자 "같은 해 입영자 중 n%".
3. 공유는 이미지 저장과 링크 복사만 지원한다. 시드 기반이라 링크로 같은 판을 다시 볼 수 있다.

## 7. 시각 체계

- 색 토큰은 `:root`에 정의하고, 라이트·다크 모두 지원한다.
  - 바탕 `--paper` 올리브 그레이 계열
  - 강조 `--accent` 국방색 녹색
  - 경고 `--warn` 황토
  - 사건 색은 긍정 녹색, 부정 적색, 일반 회색
- 서체는 본문에 IBM Plex Sans KR, 숫자·근거 줄에 Plex Mono, 통지서 제목에 명조 계열(Hahmlet)을 쓴다.
- 픽셀 장면: 생활관, 연병장, 함정, 활주로, 행정반 + 계절. v1은 정적 이미지 8~10장이다.
- 접근성: 대비 4.5:1 이상, 색 외에 아이콘·텍스트로도 상태를 구분, 키보드만으로 플레이할 수 있게 한다.
