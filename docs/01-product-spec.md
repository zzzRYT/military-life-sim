# 01. 설계 문서 (게임·규칙 설계)

> **범위 변경 (2026-10-16):** 병사만 다룬다. 이 문서의 부사관·장교·준사관 관련 내용은 더 이상 구현 대상이 아니다 (docs/04 §11).

> 한 줄: **스무 살, 입영 통지서를 받은 그날부터.** 어느 군에서, 어디서 복무할지는 고를 수 없다. 실제 병무청·국방부 통계로 뽑힌 한 번뿐인 군 생활을 끝까지 살아 본다.

- 수치 근거: [`research/official.md`](../research/official.md) (`[Sx]` 출처 코드). 공식 출처가 없는 값은 이 문서에서 **`가정`** 으로 표시하고 `rules/assumptions.json`에 모은다.

## 1. 목표와 비목표

**목표**
1. 20세 입대 직전부터 전역(또는 정년)까지를 한 판으로 체험한다. 예비군·민방위는 다루지 않는다(2026-10-14 범위 축소).
2. 신분·군종·자대가 **통계 가중 추첨**으로 정해지고, 그 결과에 따라 복무기간·진급·급여·휴가가 법령대로 달라진다.
3. 모든 사건 옆에 "실제로는 이렇다"는 근거 한 줄(출처 약칭)을 붙인다.

**비목표 (v1)**
- 실제 부대명·사단명 배정(공개 분포 데이터 없음 → 상급부대 수준까지만, §4-4).
- 여성 병사 경로(병역의무 대상 아님). 여성은 간부 경로에서만 v2에 추가.
- 대체복무·사회복무·산업기능요원 등 보충역 경로(병역판정 결과로 "보충역" 이 나오면 v1은 요약 엔딩으로 처리, §3-2).
- 멀티플레이, 계정, 결제.

## 2. 한 판의 흐름

```
[0] 시작 화면 ─ 옵션: 한 판 길이(약 15/30/45분), 실제 내 신분(비교용, 선택)
 │
[1] 20세 · 입영 전 (병역판정검사 결과 카드)
 │    신체등급 추첨 → 현역/보충역/전시근로/면제/재검
 │
[2] 첫 갈림길 ─ "입대를 미룬다" / "지금 들어간다"  (+ 간부 지원 선택지)
 │    미룬다 → 연기 사유 선택 → 시간이 흐름 → 다시 통지 (통산 2년·5회·30세 상한)
 │
[3] 추첨 ─ 신분 → 군종 → (경로·특기) 룰렛 연출 → "배치 통지서" 카드
 │
[4] 입영·양성교육 ─ 훈련소(주 단위) / 후보생·생도 과정
 │
[5] 자대·복무 ─ 월 단위 시간 흐름, 진급, 휴가, 사건, 결정
 │
[6] 전역(또는 장기복무 전환 → 정년) ─ 전역 기록 카드
 │
[7] 전역 ─ 한 판 종료 (예비군·민방위 제외, 2026-10-14)
```

- 한 판은 "**20세 → 병역의무 종료**"다. 병사는 대략 40세, 장기 간부는 계급 연령정년에서 끝난다.
- 복무 구간만 실시간으로 진행하고, 전역 후 구간은 연 단위로 압축해 1~2분 안에 끝낸다.

## 3. 입영 전 단계 (20세)

### 3-1. 병역판정검사 결과 (자동, 카드로 보여줌)

신체등급 추첨 가중치 (2024 병역판정검사, [S22]):

| 등급 | 1급 | 2급 | 3급 | 4급 | 5급 | 6급 | 7급 |
|---|---|---|---|---|---|---|---|
| 비율 | 24.0% | 31.9% | 30.7% | 7.8% | 2.2% | 0.3% | 3.1% |
| 처분 | 현역 | 현역 | 현역 | 보충역 | 전시근로역 | 면제 | 재신체검사 |

- 7급은 "재검" 결정 이벤트 → 1~6급 비율로 재추첨.
- 4급은 2021-10-14부터 **현역 복무를 선택해 입영할 수 있음** [S22] → "보충역으로 간다 / 현역을 자원한다" 결정.

### 3-2. 처분별 분기 (v1)

| 처분 | v1 처리 |
|---|---|
| 현역 (1~3급) | 본편 진행 |
| 보충역 (4급) | 현역 자원 선택 시 본편. 아니면 "사회복무요원 21개월" 요약 엔딩 (v2에서 본편화) |
| 전시근로역·면제 | 요약 엔딩: "같은 해 판정받은 222,425명 중 2.5%" 류 비교 + 간부 지원 가능 여부 안내 |

### 3-3. 첫 갈림길: 미룬다 / 지금 들어간다

| 선택지 | 부가 설명(카드에 표시) | 결과 |
|---|---|---|
| 지금 들어간다 | 입영일을 고르고 30일 뒤 입영 | §4 추첨 |
| 입대를 미룬다 | 사유를 고른다 | §3-4 |
| 간부로 지원한다 | 부사관·장교·준사관 지원 (합격은 확률) | §4 추첨에서 신분 고정, 군종·경로만 추첨 |

**"지금 들어간다"의 하위 결정 (병사)**: 징집으로 갈지(육군만), 모집병으로 지원할지. 2026년부터 공군 일반병, 2027년 접수분부터 해군·해병 일반병도 **무작위 전산선발**이라 지원해도 "붙을지 말지"는 추첨이다 [S23][S24].

### 3-4. 입영 연기 규칙 (v1 단순화 — 2026-10-15)

- 매년 "입영한다 / 1년 미룬다"를 선택. 미루면 사유 선택 (대학 진학·대학원·취업 준비·어학연수·그냥 미룸) — v1에서는 플레이버 + 소폭 스탯 차이. 진짜 기계적 레버는 **나이** 하나.
- 상한: **입영하는 해 28세**. 병역법 시행령상 재학 사유별 제한 연령(고등학교 28세, 박사 28세 등) 및 병무청 현역병입영 연기사유별 별표("28세 이상인 사람은 연기 제한"), 2026년 본인선택원 공지("입영하는 해에 28세 이상인 사람은 신청할 수 없음") 근거. ※ 기존 "법적 상한 30세" 서술은 근거 재확인 필요 — v1은 28세로 구현.
- 28세가 되면 "1년 미룬다"가 비활성화되고 자동 입영.
- (v2 정교화 후보) 아래 사유별 차등 연기 기간 테이블:

| 사유 | 연기 길이 | 조건 | 비고 |
|---|---|---|---|
| 대학 재학 (4년제) | 24세가 되는 해 12/31까지 | 재학 중 | 학교장 명단으로 자동. 2년 한도와 별개 |
| 대학 진학 예정 | 21세 해 5/31 (수능 접수 시 22세 해) | 수험생 | |
| 취업 (24세 이하) | 24세까지 | 5인 이상 정규직 | 2년 한도 미포함 |
| 모집병 지원 결과 대기 | 발표까지, 합격 시 입영일까지 | 병은 1회 | |
| 질병 | 90일 | | |
| 가족 위독·사망 | 30일(+30일) | | 사건으로 발생할 때만 |

- 연기 중 사건(학업·아르바이트·연애·친구의 입대 소식 등)은 v2에서.

### 3-5. 나이 요소 (2026-10-15)

- 부대 평균 나이 20~24를 기준으로 입영 시점에 `ageGap = 입영 나이 − 부대 평균(군종별, v1은 22)` 계산 (`rules/training.json`).
- 효과는 스탯 페널티가 아니라 이벤트 조건·문구 분기:
  - `ageGap ≥ 3`: "동기보다 n살 위로 입영" 로그 + `old_brother` 사건(맏형 노릇), `rough_day` 문구 변형.
  - `ageGap ≤ -2`: `young_one` 사건(막내).
- 구현: `S.flags.ageGap`, `content/events.js`의 `c` 조건식에서 참조.

## 4. 추첨 (핵심)

연출 (2026-10-15 구현): "새로운 인생 시작하기" → **순차 카드 공개** (신체등급 → 신분 → 군종 → 경로 → 특기). 다시 추첨 가능 (새 시드). 이후 §3 입영/연기 선택으로 이어진다. v1 카드에는 경로·특기가 원어 ID로 표시 — 라벨 테이블은 후속 작업.

**신분·군종별 훈련소** (`rules/training.json`, 2026-10-15): 입영 시 훈련소 확정 + 로그 ("육군훈련소(논산) 입소").

| 신분 | 육군 | 해군 | 공군 | 해병대 |
|---|---|---|---|---|
| 병사 | 육군훈련소(논산) | 해군교육사령부 기초군사교육단(진해) | 공군교육사령부 기본군사훈련단(진주) | 해병대교육훈련단(포항) |
| 부사관·장교·준위 | 신분별 폴백 ("부사관/장교/준사관 교육기관", 가정) — 임관 경로별 기관이 다양해 v1 단순화 |

### 4-1. 1단계: 신분

사용자가 요청한 7개 타입을 두 단계로 나눈다: **신분(병사/부사관/장교/준사관) → 군종(육·해·공·해병)**.

| 신분 | 추첨 가중치 | 근거 |
|---|---|---|
| 병사 | 0.93 | 연간 병 입영 185,866명 (2024, [S22]) |
| 부사관 | 0.05 | `가정` — 연간 임관 총원 공식 통계 없음 ([official §9-6]) |
| 장교 | 0.02 | `가정` — 육사 330·공사 235·3사 305명 등 일부만 확인 |
| 준사관 | — | 20세 직행은 사실상 불가(원사·상사 2년 이상 등 [S5 제13조]). 부사관 복무 중 **진로 이벤트**로만 진입 |

- "간부로 지원한다"를 고르면 신분은 고정되고 합격 판정만 확률로 한다.
- 가중치는 `rules/assumptions.json`에 두고, 공식 연간 임관 수치를 찾으면 교체한다.

### 4-2. 2단계: 군종

**병사** (2024 실입영 비중, [S22]):

| 육군 | 공군 | 해병대 | 해군 |
|---|---|---|---|
| 77.8% | 10.1% | 6.4% | 5.7% |

- 육군 안에서 징집 56.6% / 모집 43.4% (83,393 / 61,201).
- 공·해·해병은 **전원 모집** [S49] → "모집병에 지원했다"는 서사가 붙는다. 지원했는데 떨어지면 육군 징집으로 돌아간다(공군 경쟁률 4.97:1, [S22]).

**간부** (2023 정원 비율, [S39]):

| 신분 | 육군 | 해군 | 공군 | 해병대 |
|---|---|---|---|---|
| 부사관 (13.2만) | 65% | 14% | 15% | 5% |
| 장교 (6.9만) | 68% | 10% | 17% | 4% |

### 4-3. 3단계: 경로 (간부)

| 신분 | 경로 (20세에 가능한 것) | 의무복무 | 양성 교육 |
|---|---|---|---|
| 장교 | 사관학교 (입학 21세 미만) | 10년 | 생도 4년 |
| 장교 | 육군3사관학교 (19~25세) | 6년 | 2년 |
| 장교 | 학군사관 ROTC (대학 재학) | 육군 2년 4개월 / 법 3년 | 대학 3~4학년 |
| 장교 | 학사사관 (대졸) | 3년 | 약 17주 |
| 부사관 | 민간부사관 (18~29세) | 단기 4년 | 육군 12주 |
| 부사관 | 임기제부사관 (병 복무 중 전환) | 6~48개월 | — (병장 → 하사) |

근거: [S3 제7조][S37][S38]. 20세에 대학 재학이 아니면 ROTC·학사 경로는 비활성(사유 표시).

### 4-4. 4단계: 자대·특기 (병사)

- **육군**: 훈련소 수료 직전 전산 무작위 분류 [S12][S31]. 상급부대만 추첨한다: 지상작전사령부 / 2작전사령부 / 직할부대. 가중치는 2024 신교대 입영 계획 비율 [S22 표 2-1-4]을 쓴다.
- **공군**: 특기적성검사 + 지망 + **훈련소·특기학교 성적**이 자대에 반영된다 → 훈련소 기간 "초점" 선택이 결과에 영향.
- **해군**: 직별에 따라 육상/함정이 갈린다 → "함정 근무" 여부를 추첨.
- **해병대**: 상급부대만 추첨한다(`가정`, 균등).
- 특기(보병·운전·취사·행정·통신·의무 등) 비율은 공식 통계가 없어 `가정` 가중치를 쓴다. 자격증·전공 보유 여부(연기 기간에 얻을 수 있음)가 가중치를 바꾼다.

## 5. 복무 (신분·군종별 규칙)

### 5-1. 복무기간 ([S16][S3])

| 타입 | 복무기간 | 비고 |
|---|---|---|
| 육군 병 | 18개월 | |
| 해병대 병 | 18개월 | |
| 해군 병 | 20개월 | |
| 공군 병 | 21개월 | |
| 부사관 | 단기 4년 / 장기 7년 | 연령정년 하사 40·중사 45·상사 53·원사 55 |
| 장교 | 경로별 (§4-3) / 장기 10년 | 계급별 연령·근속정년 [S3 제8조] |
| 준사관 | 5년 | 정년 55세, 근속 32년 |

- 병 복무기간 18/20/21개월은 법정 기간에서 이미 최대로 단축한 값이라 더 줄지 않는다. 전시에는 6개월까지 연장될 수 있다 → 레어 사건으로 넣지 않는다(무거움 대비 학습 가치 낮음).
- 종료일 계산은 `개발 설계 §4` 날짜 엔진(민법 160조 만료일)을 따른다.

### 5-2. 단계 타임라인 (병사)

```
입영(가입소 1주) → 신병교육 5주(해병 6주) → [후반기 교육 2~8주, 특기병] → 자대
→ 신병보호 1~2주 → 이병 → 일병(+2개월) → 상병(+6) → 병장(+6) → 전역
```

- 진급: 이병 2 → 일병 6 → 상병 6개월, **매월 1일자** [S5 제32조][S9 제22조]. 조기진급(일병 4·상병 5개월)은 인원의 10%(전투부대 20%, 경계부대 30%)까지만 가능하다 → 성과 점수 상위일 때 확률 사건.
- 진급 지연: 징계 시 1~3개월 [S5 제36조]. 그래도 만기전역 달에는 병장으로 전역할 수 있다 [S5 제33조②].

| 병장 | 150만 |

- 장병내일준비적금: 월 최대 55만 원 납입, 정부가 원금 100%를 매칭한다(전역 후 만기까지 유지할 때만).
- 결정 사건으로 넣는다: "적금에 얼마를 넣을까?" 0 / 30만 / 55만. 이병 월급 75만에서 55만을 넣으면 생활비가 부족해진다 → 행복↓, 전역 목돈↑.
- 간부 봉급: 하사 1호봉 213.3만, 소위 1호봉 215.0만 원 (2026, 봉급만) [S6]. 수당은 `가정`.

### 5-4. 휴가

- 위로 7일 이내, 포상 10일 이내, 청원(본인 요양) 연 30일 이내 [S8].
- 병 정기휴가 군별 일수는 **공식 표 없음**. 18개월 24일(차선)을 쓰고, 해군 27일·공군 28일은 같은 비율로 계산한 값이다(`가정`). 화면에 "추정" 배지를 단다.
- 간부 연가: 연 21일 [S8 제10조].

### 5-5. 간부 진급·장기복무

- 진급 최저기간 [S3 제26조]: 부사관은 하사 2년 → 중사 5년 → 상사 7년 → 원사. 장교는 근속 기준과 직전 계급 복무 기준을 함께 본다(중위 1/1, 대위 3/2, 소령 11/6, 중령 17/5, 대령 22/4).
- 진급은 "자격일"에 **선발 결정 사건**으로 처리한다. 선발률은 `가정`이다.
- 의무복무 만료 1년 전에 "장기복무에 지원할까?" 결정이 나온다. 합격 시 의무복무 10년(장교)·7년(부사관)이 다시 적용된다.
- 부사관 상사 2년 이상이면 "준사관 시험에 응시할까?" 결정이 나온다 → 준사관 경로.
- 정년이 되면 정년이 된 달의 다음 달 말일에 전역한다 [S3 제36조①].

### 5-6. 주특기 메커니즘 (병사, 2026-10-15)

- `rules/soldier-mos.json`: 병사 주특기 90개 (육 29·해 17·공 27·해병 17), 엔트리마다 `leave`(휴가 상중하)·`difficulty`(1~5)·`injuryRisk`(1~3)·`injuryTypes`·`src`를 기록 — 전부 `가정`.
- 추첨: 병사는 `drawAll`에서 군종별 키를 **균등 추첨**한다 (병과별 전형 통계가 공개되지 않음). 비병사는 기존 `weights.mos` 테이블을 그대로 쓴다 (하위 호환).
- 입영 시 `S.mosMech`에 프로필을 부착한다. 휴가 지수 반영: 상(3)→×1.2 / 중(2)→×1.0 / 하(1)→×0.8.
- 월간(serve 페이즈): `difficulty` 4 이상이면 체력 −2, 3이면 −1, 5면 멘탈 −1 추가. 부상 판정은 월 `injuryRisk × 0.4%` → 발생 시 3개월 회복(`flags.injured`) + 체력 −10·멘탈 −5. 전부 `가정`.

### 5-7. 취미 축 (2026-10-15)

- 자대 배치 후 취미 1개 선택 (`chooseHobby`, `rules/hobbies.json` 20종). v1은 변경 없음.
- 매월 선택 취미의 `effects`가 스탯에 반영된다 (운동→체력↑, 독서·자격증→숙련↑, 게임→멘탈↑·돈↓ 등). 효과값 전부 `가정`.
- 취미 사건 10종(`content/events-hobby-bonds.js`)은 선택한 취미와 맞물려 발생한다 (`S.hobby` 조건).

### 5-8. 관계 축 (2026-10-15)

- `S.bonds = { lover, family }`. lover 유무는 입영 전 50% 추첨(`가정`, 있으면 70), family는 60 고정.
- lover가 있으면 매월 방치 감쇠 −1 (`가정`). 값이 낮아지면 **곰신 위기** 결정 사건 → 이별 선택 시 고무신, 축 종료 (`lover = null`).
- 관계 사건 10종(`content/events-hobby-bonds.js`): 면회·연락·수료식 가족 만남·부모 생신 등. 면회 시간·청원휴가 등 제도 사실은 근거를 붙인다.

## 6. 사건과 결정

### 6-1. 종류

| 종류 | 성격 | 예 |
|---|---|---|
| 사건 | 자동 발생, 로그 한 줄 + 근거 | "혹한기 훈련이 시작됐습니다" |
| 중대 결정 | 시간 정지, 2~5지 | 적금 금액, 장기복무 지원, 휴가 시기, 조기진급 노력 |
| 작은 선택 | 가벼운 2지 | "PX에서 냉동식품을 살까?" |
| 잠시 멈춤 | 고정 시점의 성찰 | 입영 첫날 / 100일 / 상병 / 전역 D-30 |

### 6-2. 단계별 사건 풀 (v1: 기본 77 + 주특기 40 + 취미·관계 20 = 137)

| 단계 | 사건 예 | 근거 |
|---|---|---|
| 입영 전 | 판정검사, 연기 사유, 친구 입대, 아르바이트, 수능 | [S13] |
| 훈련소 (주 단위) | 1주 체력검정 / 2주 영점사격 / 3주 수류탄 / 4주 각개전투·20km 행군 / 5주 수료식, 불침번, 주말 휴대폰 1시간 | 공개 훈련소 안내 |
| 자대 초기 | 신병보호, 신병위로외박, 첫 월급, 적금 가입 | [S34] |
| 상시 | 혹한기·혹서기, 유격, 화생방, 사격 우수(포상휴가), 휴가, 외출·외박, 면회 | [S8] |
| 위기 | 부상, 질병 입실, 갈등, 고민 → **장면 묘사 없이** 국방헬프콜 1303 안내 | 안전 규칙 §6-4 |
| 간부 | 보직 이동, 진급 심사, 장기 지원, 결혼·관사, 정년 | [S3] |

- 발생률은 공식 통계가 거의 없다 → 모든 확률은 `가정`이고 근거 줄에는 **제도 사실**만 적는다(예: "포상휴가는 10일 이내로 줄 수 있습니다 (군인 복무기본법 시행령)"). 지어낸 통계는 쓰지 않는다.

### 6-3. 상태값

`체력`, `멘탈`, `전투력/숙련`, `관계(동기·선임)` 0~100, 그리고 `돈`(월급·적금), `휴가 잔여`, `성과 점수`(진급·포상·공군 자대 배정에 사용).

- 관계·취미 축 (§5-7·§5-8): `S.bonds = { lover (null 가능), family }` 0~100, `S.hobby`는 선택한 취미 id (월간 `effects`).

### 6-4. 콘텐츠 안전

- 첫 화면에 "가혹행위·사고·자살 같은 무거운 주제가 실제 제도대로 다뤄질 수 있습니다"를 고지한다.
- 무거운 사건은 장면을 그리지 않고 결과와 도움 창구만 보여준다(국방헬프콜 1303, 109).
- 특정 부대·실존 인물을 지목하지 않는다.
