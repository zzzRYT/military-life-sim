# 군 생활 시뮬레이터 (가칭)

스무 살, 입영 통지서를 받은 그날부터. 어디서, 어떤 신분으로 복무할지는 고를 수 없다.
병무청·국방부 공개 통계로 뽑힌 한 번뿐인 군 생활을 입영 전부터 전역까지 살아 보는 웹 시뮬레이터.
